## ✳ About

**Type Riot** is a playful, browser-based typography experiment. Type a word, change its style, adjust the spacing and rotation, explore color combinations, and create unexpected typographic compositions.

The project explores the idea that typography can be more than readable text — it can be the artwork itself.

## Features

- **Live text editor** — enter your own word or short phrase.
- **Multiple type styles** — experiment with condensed, block, distorted, soft, monospaced, and editorial looks.
- **Typography controls** — adjust font weight, letter spacing, and rotation.
- **Color playground** — switch text colors and background colors.
- **Random generator** — discover unexpected combinations with one click.
- **Clickable poster gallery** — select an example to load its settings into the editor.
- **Responsive layout** — adapts to desktop and mobile screens.
- **Lightweight setup** — no framework, backend, or API key required.

## Getting Started

### Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.

```bash
git clone https://github.com/YOUR-USERNAME/type-riot.git
cd type-riot
```

Then open `index.html` in your browser.

> Google Fonts load over the internet. System fallback fonts are included if they are unavailable.

## Live Demo

You can publish Type Riot for free with **GitHub Pages**:

1. Create a GitHub repository named `type-riot`.
2. Upload `index.html`, `README.md`, and the `assets/` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish the site. Your URL will look like:

   `https://YOUR-USERNAME.github.io/type-riot/`

Replace `YOUR-USERNAME` with your GitHub username. GitHub may take a few minutes to publish the first time.
